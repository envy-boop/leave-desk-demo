# Leave Desk: portfolio demo

An interactive demo of a leave management system I designed and built with Google Apps Script and Google Sheets.
**Everything on this page is fictional.** Names, departments and numbers are made up, and there is no company data.

## What to try

1. Follow Flo's guided tour on first load (the **?** button replays it).
2. In **My leave**, pick dates and watch working days count live, skipping weekends and Nigerian public holidays.
3. Send a request, switch to **Admin**, and approve, decline or ask for changes (a comment is required for the last two).
4. Open the **envelope** icon to see the emails the real system sends.
5. Switch between dark and light themes.

## About the real system

- Sign-in restricted to company work emails
- Leave balances and policy rules stored in Google Sheets
- Approval, decline and welcome-back emails through Gmail, team calendar through Google Calendar
- Admin dashboard with 1, 3, 6 and 12 month views, pending requests, handover and cover confirmation
- Daily automations for reminders, escalation and return notices

This demo is a single static HTML file with no external dependencies.
